# Illusion Lab / 錯視ラボ

15問の錯視を「見る → 答える → VERIFY → 理由を知る」で体験する、静的Webアプリです。HTML / CSS / JavaScriptと独自描画のSVGのみ。画像・フォント・ライブラリ・外部APIへの依存はありません。

## 起動

`index.html`をブラウザーで開いてください。ビルド・インストール不要です。ローカルサーバーを使う場合は、リポジトリで`python3 -m http.server 8000`を実行して `http://localhost:8000` を開きます。

## GitHub Pages

このリポジトリをGitHubへpushし、Settings → Pages → Build and deploymentで **Deploy from a branch** を選択します。公開するブランチと **/ (root)** を指定して保存してください。アセットはすべて相対パスで、プロジェクト配下への公開に対応しています。`.nojekyll`によりJekyll処理を省略します。

## ファイル

- `index.html`：画面の土台・遊び方
- `style.css`：PC、iPad、スマートフォン対応。モーション削減設定にも対応
- `questions.js`：15問のデータ、調整定数、寸法・正解・選択肢
- `app.js`：SVG描画、VERIFYアニメーション、回答フロー、結果と再検証

## 差を調整する

`questions.js`の`TUNING`で比率を指定します。例：`muller: 0.07` は基準の線より7%長い線です。`larger: 'a' | 'b' | 'same'`で大きい側を指定し、`base`を基準寸法とします。寸法は`dimensions()`から計算し、SVG、正解、検証値のすべてに使用します。円の`base`は半径ですが、検証画面は直径を表示します。

平行は`angle`（度）、中心は`offset`（線の全長に対するずれ）、直線は`bend`（中央での湾曲量）で管理します。正解は数値から導出します。明るさはRGB各成分の比率、色はHSL明度の比率で、知覚上の明るさの比率ではありません。RGBは小数値もCSSで表現できますが、設定値の調整時は画面で差を確認してください。

問題順は意図的に固定しています。最初の2問は典型例、3問目から実際の差を混ぜます。同じ問題と異なる問題は交互の固定パターンにならないよう配置しています。リトライで順番や図形は変わりません。

## 検証表示

- 長さ：背景消去 → 同じ左端に整列。縦線は回転。端点ガイド・寸法を表示
- 円：周囲消去 → 同倍率で2倍に拡大して中心を重ねる。実線と青い破線で輪郭の一致・差を確認
- 平行・直線：背景消去 → 方眼・直線ガイドを表示
- 中心：背景消去 → 真の中点と左右距離を表示
- 明るさ・色：背景を共通化 → 2つの四角を接する位置へ移動

図形の数値はSVGの座標単位であり、端末上の物理ピクセルではありません。レスポンシブ表示では図形全体を同じ倍率で縮小します。色の見え方はディスプレイ・環境に依存します。スコアはゲームの正答数で、視覚能力の評価ではありません。

## 著作権

すべての図形をコードで独自描画しています。既存の錯視画像のダウンロード・コピーは行っていません。

## 開発時の確認

`tests/browser-check.cjs`はPlaywrightを使う任意の開発用テストです（アプリの実行には不要）。Playwrightが使える環境でサーバーを起動し、`APP_URL=http://localhost:8000 node tests/browser-check.cjs`を実行します。必要に応じて`CHROME_PATH`にChromeの実行ファイルを指定します。全15問の採点、VERIFY後の寸法比・整列、色の一致、全問「同じ」の結果、再挑戦、振り返り、320〜1440pxの表示、通常・モーション削減時の動作を確認します。
